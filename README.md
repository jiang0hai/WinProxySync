# WinProxySync

> Windows System Proxy → PowerShell / CLI Environment / Git Synchronizer

- 🇨🇳 [简体中文](README.zh-CN.md)
- 🇺🇸 [English](README.en-US.md)  
WinProxySync 是一个 Windows 系统代理同步工具。

它读取 Windows 标准系统代理状态，并将代理信息同步到开发环境

WinProxySync synchronizes the Windows system proxy with PowerShell/CLI environment variables and optional Git global proxy settings.
